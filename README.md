# CFP NDOULO MANAGER — Version 4 (prototype financier)

## Module financier
Chaque recette encaissée est répartie automatiquement entre les enveloppes selon les taux validés :
- Matériels didactiques et pédagogiques : 40 %
- Matériels et produits d'entretien : 5 %
- Entretien et maintenance : 9 %
- Restauration (réunion et mission) : 5 %
- Communication : 2 %
- CAI – Insertion et partenariat : 5 %
- Transport : 1 %
- Activités socioéducatives des apprenants : 5 %
- Assurance santé : 1 %
- APE : 1 %
- Écologisation et sécurité : 1 %
- Confection blouse : 3 %
- Genre : 1 %
- Dépenses diverses : 2 %
- Prestation de service : 10 %
- CAP, cellule pédagogique et examen : 2 %
- Crédit téléphonique : 2 %
- Appui social : 1 %
- Cotisation Collectif des établissements et Table de concertation : 1 %
- Frais bancaires : 1 %
- Livebox (Internet) : 2 %
- Fonds résiduel / réserve : reliquats d'arrondi éventuels uniquement.
- Élaboration PSD (suite) : ressource spécifique séparée, hors répartition ordinaire.

Alerte si une enveloppe passe sous 5 000 FCFA. Toute dépense supérieure à 15 000 FCFA nécessite une autorisation préalable. Une dépense ne peut pas être enregistrée si le crédit disponible est insuffisant. Le gestionnaire peut renseigner le solde bancaire du relevé.

## Installation
Décompresser le ZIP et publier les fichiers sur un hébergement HTTPS. Sur Samsung, ouvrir l'adresse dans Chrome, menu ⋮, puis « Installer l'application » ou « Ajouter à l'écran d'accueil ».

## Limites
Cette livraison reste un prototype local : données stockées dans le navigateur, sans synchronisation ni authentification sécurisée. Les espaces gestionnaire/directeur, l'envoi automatique mensuel à cfpndoulo@gmail.com, la clôture annuelle verrouillée, les sauvegardes serveur et le journal d'audit nécessitent un backend de production. Ne pas saisir de données financières confidentielles avant cette mise en production.
